# Direction cards

Process note (honest): `playwright(py)` missing, so `ref_board.py` could not capture reference sites; references below are **not seen on screen** — borrowed from known design language only. The six-thumbnail sheet was skipped to save effort; the 3 alternates exist as cards only.

## D1 — Counter (chosen candidate 1)
- Logic/source: best designer — Dieter Rams / Braun product UI (calm, functional, one signal colour).
- Borrowed: neutral light-grey field, every control looks like a physical device button, a single orange signal used only for "needs you now", strict 8px grid, numerals in a mono/tabular face.
- Hero material: big tabular numerals (the quantities) on matte surfaces; procedural paper-grain-free flat colour.
- Skeleton: bottom tab bar per role; rows not cards; sticky bottom primary action.
- Boldness: quantities are the largest thing on every screen; chrome nearly vanishes.
- Form from content: a storekeeper's weighing scale — the number is the interface.
- Board: hub-and-spoke — Home phone large centre (1.25×), other four orbit with thin lines labelled by hand-off ("Requester sends → Keeper picks → Runner signs → Custodian balances").

## D2 — Cold Room (chosen candidate 2)
- Logic/source: reality reference — Flighty (Apple Design Award 2023): live-status-first cards, status colour as the hierarchy. (not seen on screen)
- Borrowed: dark surfaces readable in dim storerooms, large status chip leading each card, bottom sheets for actions, progress rail showing where a request is in its life.
- Hero material: the **life rail** — each request/issue shows a horizontal rail: Requested → Staged → At door → Confirmed, current stop lit; ledger rows appear under it as small mono lines.
- Skeleton: card stack + bottom action sheet; top segmented control instead of tabs.
- Boldness: dark ice-blue palette with exactly three state colours (amber expiry, red lock/decline, mint confirmed).
- Form from content: the two-stage append-only issue is a journey — draw it as one.
- Board: dark staged flow — phones left-to-right along one long horizontal rail line that runs behind them and lights up per step; background is deep blue-black with faint cold-room frost grain (CSS noise).

## D3 — Day-Dot (chosen candidate 3, the bold one)
- Logic/source: roulette — "hard-edged functional brutalism" crossed with kitchen day-dot FIFO labels.
- Borrowed: thick black rules, slab rows full-width, huge stepper buttons usable with gloves, a colour per day-of-week (day-dot) marking lot received date so FIFO is readable at a glance.
- Hero material: the day-dot colour chips themselves (7 fixed hues) + heavy grotesque numerals.
- Skeleton: full-width slab list, persistent bottom bar with one giant action, no tabs (role switch via top-left sheet).
- Boldness: white paper, 3px black borders, saturated day-dot colours; extremely high contrast.
- Form from content: kitchens already label stock with day-of-week dots; the app speaks that language.
- Board: staggered stairs — phones step down diagonally with big black slab captions, white background with a giant day-dot strip (Mon–Sun) as the board's top rule.
